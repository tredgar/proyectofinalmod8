# 🛒 Catálogo Interactivo de Productos

## 📝 Descripción del Proyecto
Aplicación web full-stack proyecto final. Permite explorar productos, filtrarlos por categoría/precio, buscar en tiempo real y gestionar un carrito de compras interactivo.

## 🛠️ Tecnologías Utilizadas
- **Frontend:** React
- **Backend:** Node.js, Express
- **Control de Versiones:** Git & GitHub

- **Control de versiones:** Trabajo mediante ramas de características (*feature branches*) para integrar el código mediante Pull Requests hacia la rama `main`.
- **Estructura del código:** Proyecto desacoplado con servidor Express en la carpeta `/backend` y cliente React en la carpeta `/frontend`.
